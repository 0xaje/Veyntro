# Veyntro

Every commitment accounted for.

Veyntro is being built to help DAOs and communities set money aside for approved work without promising the same funds twice. The Commitment Firewall will enforce backed commitments, limited payments, and the return of unused money on NEAR.

## Current status

Development is in progress. The public application and Commitment Firewall contract are not implemented yet.

Verified on NEAR testnet:

- Council account: `aje-veyntro.testnet`.
- SputnikDAO: `veyntro.sputnikv2.testnet`.
- DAO creation transaction: [6oV4Y8DX7hxXK2FB2hietaongMPtKzZzbaWazMAyP8JX](https://explorer.testnet.near.org/transactions/6oV4Y8DX7hxXK2FB2hietaongMPtKzZzbaWazMAyP8JX).

A real DAO-approved call to the Veyntro contract is the next integration gate. DAO creation alone does not verify that gate.
