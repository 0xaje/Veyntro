# Veyntro: 2–3 minute demo recording guide

Record the real hosted site and linked testnet receipts. Use a fresh guest window for public reads. Show the browser address and transaction status when it helps. Do not show a recovery phrase, private key, GitHub secret, or wallet approval dialog you do not intend to sign. The recorded completed flow needs no new transaction.

| Time | Show | Say in simple English |
| --- | --- | --- |
| 0:00–0:25 | [DAO approval](https://veyntro-web.onrender.com/governance), request 4 **Failed during execution**, then its [rejected receipt](https://explorer.testnet.near.org/transactions/HnMJXawR3zD6onxcQe6n27wrYVQ1X591U7r4miPrnEtt). | “A DAO can vote to promise money it has already set aside. The Firewall refused this extra promise on NEAR.” Distinguish a DAO vote from successful contract execution. |
| 0:25–0:50 | [Overview](https://veyntro-web.onrender.com/), **Money available**, **Money set aside**, and the latest final block. | “Only money left after existing promises and the safety reserve is available. These values come from the live testnet contract.” Do not quote a fixed balance; it can change. |
| 0:50–1:15 | Back to DAO approval, request 14 **Approved**; expand “Review every contract action.” | “SputnikDAO approved 0.05 testnet NEAR for specific work. Approval set money aside; it did not pay anyone yet.” |
| 1:15–1:45 | [Commitment 4](https://veyntro-web.onrender.com/commitments/4): recipient, checked commit, completed state, zero left. Optionally show the [successful work checks](https://github.com/0xaje/Veyntro/actions/runs/42136893325) and [restricted verifier run](https://github.com/0xaje/Veyntro/actions/runs/42275081154). | “A restricted checker confirmed the agreed GitHub run. Anyone can follow the record without connecting a wallet.” |
| 2:15–2:35 | Optional [expiry release receipt](https://explorer.testnet.near.org/transactions/3bWgBZGtCJEHxdgo4Kcm995fXPXzskbfXbpKSG5enMv1) and the [judge page](../JUDGES.md). | “Unused promises can expire and return to available money. This site shows one testnet DAO; setup for other DAOs and a general public work-check service are not offered.” |
