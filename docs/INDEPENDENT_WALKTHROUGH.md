# Independent Veyntro walkthrough — 2026-11-06

Give this page to a person who did not build Veyntro. The public steps need no wallet, payment, or test tokens. Record what they actually observe; this document is a test plan, not a completed external review.

1. Open https://veyntro-web.onrender.com/ in a fresh browser. Without coaching, ask: What problem does this solve? What is the difference between money available and money set aside? Note their words and any confusing label.
2. Open https://veyntro-web.onrender.com/commitments/4. Find the approved amount, payment account, work check, and Completed state. Follow the payment-record link to Activity. Find payment 6 (0.05 testnet NEAR to `aje.testnet`), then follow its transaction link and compare the recipient and amount. The direct receipt is https://testnet.nearblocks.io/txns/4WDbT9xDxNgJVgGcgeSwcTex7GGrmT2U3tsLPH94jKex. A receipt marked Success should agree with the public record; report any difference.
3. Open DAO approval. Find request 14 and explain what approval does. Check that it is distinguishable from a completed payment. No new proposal or vote is needed for this review.
4. If the tester already has a NEAR **testnet** wallet, optionally connect, disconnect, reconnect and refresh. Check the chooser in both light and dark mode and at a narrow phone width. Do not sign a financial action for this walkthrough. Never share a recovery phrase or private key.
5. Report the date/time, device and browser, exact page URL, action, expected result, actual result, and a screenshot for each problem. Record whether the tester could explain the promise and trace the 0.05 testnet payment without help.
